Conociendo el mundo

Personal tool for publishing my own AI-generated short videos.

What it does

Conociendo el mundo is a private desktop tool used by a single creator. It assembles short vertical videos (script, narration, images and captions created with AI tools) and publishes them to the creator's own TikTok account through TikTok's official Content Posting API. Every video is labeled as AI-generated content.

It is not a public service: it does not offer accounts, it does not access other people's TikTok accounts, and it has no servers that store user data.

Qué hace

Conociendo el mundo es una herramienta de escritorio privada que usa un solo creador. Monta videos cortos verticales (guion, narración, imágenes y subtítulos creados con herramientas de IA) y los publica en la cuenta de TikTok del propio creador mediante la Content Posting API oficial de TikTok. Cada video se marca como contenido generado con IA.
